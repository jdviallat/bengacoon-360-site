# Fonctionnalités — Bengacoon 360 / Cocoon

**Une application, deux visages.** Bengacoon 360 réunit toute la gamme bien-être Bengacoon
(8 applications devenues modules) dans une seule app mobile : un profil unique, un suivi
transversal, un accompagnement quotidien. Deux **éditions** sont construites sur le même code.

## Les deux éditions

| | Cocoon | Bengacoon 360 |
|---|---|---|
| Public | Familles & particuliers | Thérapeutes / praticiens |
| Accueil | **Ma famille** + agenda du foyer | **Mes clients** + agenda du cabinet |
| Suivi | Profils des proches (rituels, cures, prises) | Dossiers clients : RDV, animaux, séances, chronologie, progression |
| Séances | Rituel du jour corrélé à l'état émotionnel | Atelier multi-modalités : hypnose, PNL, communication animale, sophrologie, magnétisme + outils (tirage, pendule, pierres, fleurs, nombres) |
| Exports | Sauvegarde JSON | + Comptes-rendus de séance **PDF / Word / Excel** personnalisables |

### Cocoon — pour votre famille

- Prendre soin du bien-être de toute la famille en un seul endroit : profils des proches, agenda du foyer.
- Ne plus oublier une prise : médicaments, cures de fleurs de Bach, compléments — posologie, horaires, rappels et photos d'ordonnances.
- Instaurer des rituels quotidiens : respiration, rituel du jour corrélé à l'état émotionnel, bilan du soir.
- Suivre l'évolution de chacun : courbes d'humeur, journal, séries de jours.
- Accéder à tous les outils bien-être (pierres, fleurs de Bach, oracle, numérologie, radiesthésie, souffle, forme, santé) sans jongler entre 8 applis.
- Protéger l'intimité : verrouillage Face ID / empreinte / code, données 100 % locales.

### Bengacoon 360 — pour votre cabinet

- Un seul dossier par client, utilisable par TOUS les outils : fini les doubles saisies.
- Séances multi-modalités : hypnose, PNL, communication animale, sophrologie, magnétisme + tirage, pendule, pierres, fleurs, nombres dans la même séance.
- Mesurer l'effet : bilans avant/après, chronologie, progression.
- Comptes-rendus professionnels : PDF / Word / Excel personnalisables depuis le dossier client.
- Import du carnet de contacts, gestion des RDV et des animaux.
- Modules personnels (forme, numérologie…) séparés des dossiers clients.
- Feuille de route : gestion cabinet complète à venir (prestations, paiements, agenda synchronisé).

| Module | Contenu réel embarqué |
|---|---|
| **Oraclecoon** | 104 cartes-totems (2 jeux, visuels et dos officiels), tirages 1·2·3 cartes, 8 parcours guidés thématiques, 283 combinaisons interprétées, endroit/inversé, journal des tirages |

| **Numerocoon** | Thème complet (chemin de vie, expression, âme…), grille d'inclusion, dettes karmiques, horoscope jour/semaine, compatibilité 8 dimensions, guidance, journal |

Chaque module a sa **barre d'onglets en bas** (1ᵉʳ onglet = accueil du module), sa **roue de
réglages propres** (préférences persistées), et propose de **« garder une trace »** après chaque
usage (humeur avant/après) pour alimenter le suivi global.

## Fonctionnalités transversales

- **Thème clair pastel** par défaut (lavande, sauge, rose poudré, or doux) — « nuit étoilée » en option.
- **Accueil vivant** : famille/clients d'abord, agenda, phase de lune réelle (calcul astronomique), message du jour, blocs modules à action immédiate.
- **Profil global** (identité, naissance) repris par les modules (le thème numérologique se calcule tout seul).
- **Verrouillage** Face ID / empreinte / code 6 chiffres (stockage sécurisé), re-verrouillage en arrière-plan.
- **Mes prises** : moteur unique posologie/horaires/alertes/photos (produit & ordonnance) pour médicaments, cures de Bach et compléments sport.
- **Suivi** : graphes d'activité 14 jours, courbe d'humeur, stats par module, série de jours.
- **Agenda unifié** : RDV clients/famille + rappels.
- **Import du carnet de contacts** pour créer les fiches clients/proches.
- **Rappels quotidiens** (rituel, souffle, bilan du soir) + alertes de prise.
- **Journal transversal** auto-alimenté + **recherche globale** dans toutes les bibliothèques.
- **Sauvegarde / import** JSON complet (fusion ou remplacement).
- **Mises à jour** : vérification au démarrage via manifestes, écran Nouveautés.
- Contenu en 9 langues (fr en de it pt es sv no fi) — interface : fr pour l'instant.

## Vie privée

Données 100 % locales, aucune télémétrie, aucun compte. **Jamais médical** : l'app enregistre
et organise, elle n'interprète pas.
